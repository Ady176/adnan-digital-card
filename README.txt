DIGITAL BUSINESS CARD — MUHAMMAD ADNAN ASHRAF

Contents:
- index.html : mobile-friendly digital card with Save Contact, Call, Email, WhatsApp and Share
- contact.vcf : downloadable contact file

PUBLISHING:
1. Upload BOTH files to a publicly accessible HTTPS static website (e.g. GitHub Pages, Netlify or your company's website).
2. Open the published link on a phone and test Save Contact.
3. Only AFTER the link is live, generate a QR code encoding that exact published HTTPS URL.
4. Replace the existing QR on the printed card with the URL QR, without using image generation to redraw it.

Note: This ZIP is NOT yet hosted. No working URL-based QR can be generated before the final public link is known. Do not put the local file path into a QR code.
